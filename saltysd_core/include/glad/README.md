# glad headers

`egl.h`, `gl.h`, `gles2.h`, `vulkan.h` are generated by glad 2.0.8 (https://glad.sh, generator URLs in each
header) and used for their types, constants and function pointer typedefs only, without glad's loader.

Generated code: `(WTFPL OR CC0-1.0) AND Apache-2.0` (SPDX line in each header). The Apache-2.0 part comes from
the Khronos specifications the headers are generated from.

- `LICENSE`: glad's license file (glad itself: MIT; Khronos specifications: Apache-2.0; EGL headers: Khronos'
  MIT-style license)
- `LICENSE-Apache-2.0.txt`: full text of the Apache License 2.0
